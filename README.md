# GymDashboard Frontend

## Description
This is the frontend for the **GymDashboard** project which provides the user interface with proper integration and communication with the backend.

---

## Technologies Used

- **Chakra UI** - Component library for building accessible UI
- **React.js** - JavaScript library for building user interfaces
- **React Hook Form** - Form handling in React
- **Tailwind CSS** - Utility-first CSS framework
- **React Router DOM** - Client-side routing
- **TypeScript** - Static typing for JavaScript
- **Axios** - HTTP client for API requests
- **React Toastify** - Toast notifications
- **Zod** - Schema validation

---

## Installation

### 1️⃣ Clone the repository
```bash
git clone https://github.com/Carlos9190/GymDashboard_Frontend.git
cd GymDashboard_Frontend
```

### 2️⃣ Install dependencies
```bash
npm install
```

### 3️⃣ Configure environment variables
Create a .env file in the project's root directory and define the following variable:
```env
VITE_API_URL=http://localhost:4000/api
```

### 4️⃣ Start the development server
```bash
npm run dev
```
